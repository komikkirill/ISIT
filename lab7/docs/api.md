# Документация REST API «Управление номерным фондом гостиницы»

## Общая информация
*   **Базовый URL:** `http://localhost:8000/api`
*   **Формат данных:** JSON (кодировка UTF-8).
*   **Аутентификация:** не требуется (в рамках учебной работы).

---

## 1. Ресурс: Бронирования (`/api/bookings`)

### 1.1. Получить список броней
*   **Метод:** `GET`
*   **URL:** `/api/bookings`
*   **Параметры запроса (query):** `?status=new` (опционально, фильтр по статусу: `new`, `in_progress`, `done`).
*   **Успешный ответ (200 OK):** Массив объектов бронирований.
```json
[
    {
        "id": 1,
        "room_id": 1,
        "guest_name": "Иванов Иван",
        "check_in": "2024-12-01",
        "check_out": "2024-12-05",
        "status": "new"
    }
]
```

### 1.2. Получить одну бронь

*   **Метод:** `GET`
*   **URL:** `/api/bookings/{id}`
*   **Успешный ответ (200 OK):** Объект бронирования.
*   **Ошибки:** `404 Not Found` (если брони с таким ID нет).

### 1.3. Создать бронь

*   **Метод:** `POST`
*   **URL:** `/api/bookings`
*   **Тело запроса (JSON):**

```json
{
    "guest_name": "Петров Петр",
    "room_id": 2,
    "check_in": "2024-12-10",
    "check_out": "2024-12-15"
}
```
### 1.4. Обновить бронь

*   **Метод:** `PUT` или `PATCH`
*   **URL:** `/api/bookings/{id}`
*   **Тело запроса (JSON):** любые поля для изменения (например, `{"status": "done"}`).
*   **Успешный ответ (200 OK):** Обновленный объект.
*   **Ошибки:** `404 Not Found`, `422 Unprocessable Entity`.

### 1.5. Удалить бронь

*   **Метод:** `DELETE`
*   **URL:** `/api/bookings/{id}`
*   **Успешный ответ (204 No Content):** Тела ответа нет.
*   **Ошибки:** `404 Not Found`.

## 2. Ресурс: Номера (`/api/rooms`)

### 2.1. Получить список номеров

*   **Метод:** `GET`
*   **URL:** `/api/rooms`
*   **Успешный ответ (200 OK):** Массив номеров.

### 2.2. Создать номер

*   **Метод:** `POST`
*   **URL:** `/api/rooms`
*   **Тело запроса (JSON):**

```json
{
    "title": "Люкс",
    "description": "Двухкомнатный номер с видом на море"
}
```

### 2.3. Удалить номер

*   **Метод:** `DELETE`
*   **URL:** `/api/rooms/{id}`
*   **Успешный ответ (204 No Content).**
*   **Ошибки:** `409 Conflict` (если на этот номер есть активные бронирования).

---

## 3. Ресурс: Гости (`/api/guests`)

### 3.1. Создать гостя

*   **Метод:** `POST`
*   **URL:** `/api/guests`
*   **Тело запроса (JSON):**

```json
{
    "name": "Сидоров Сидор",
    "phone": "+79991234567",
    "email": "sidorov@example.com"
}

```

## 4. Коды ошибок

Все ошибки возвращаются в формате JSON:

```json
{
    "error": "Текст ошибки",
    "errors": {
        "поле": "Текст ошибки валидации"
    }
}
