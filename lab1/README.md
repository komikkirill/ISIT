# isit-lab1
# Лабораторная работа №1
## Анализ предметной области информационной системы
Вариант 18 Смирнов К.А. ИТД-31. Система управления гостиничными номерами
## 1. Описание предметной области
Предметной областью является деятельность гостиничного предприятия (отеля, хостела, гостевого дома) по управлению номерным фондом. Основные бизнес-процессы включают в себя: ведение учета номеров, управление категориями и тарифами, обработку запросов на бронирование, регистрацию проживающих гостей и расчеты за проживание.
## 2. Проблема и цель системы
В настоящее время учет номерного фонда и обработка заявок на бронирование ведутся разрозненно: часть информации хранится в бумажных журналах на ресепшн, часть — в электронных таблицах. Это приводит к следующим трудностям:
Двойные бронирования — один и тот же номер может быть забронирован дважды из-за отсутствия единого календаря занятости.
Потеря данных о гостях — при повторном визите сложно восстановить историю проживания и особые пожелания гостя.
Низкая скорость обслуживания — в часы заезда и выезда администраторы тратят много времени на поиск свободных номеров и ручное оформление документов.
# Цель:
-исключение двойных бронирований за счет автоматического контроля занятости номеров;
-единую базу данных гостей с историей их проживания;
-автоматизацию операций бронирования, заселения (Check-in) и выселения (Check-out);
## 3. Анализ предметной области
Гость - Физическое лицо - ID, ФИО, паспортные данные, телефон, email, дата регистрации
Номер - Комната - ID, номер комнаты, этаж, площадь, вместимость, текущий статус
Категория номера - Тип номера - ID, название, цена за ночь, описание, список удобств
Бронирование - Заявка на резервирование номера - ID, дата заезда, дата выезда, статус, стоимость
Проживание - Факт заселения - ID, дата фактического заселения, дата выселения, итоговая сумма
# Связи между объектами
Гость создаёт Бронирование (один гость, много бронирований)
Бронирование оформляется на Номер (одно бронирование — один номер)
Номер принадлежит Категории (много номеров — одна категория)
Проживание связывает Гостя и Номер в конкретный период времени
Проживание может быть создано на основе Бронирования
## 4. Пользователи и роли.
Администратор | Сотрудник ресепшн, управляющий операциями с номерами | Поиск свободных номеров, оформление бронирований, заселение, выселение, изменение статуса номера, регистрация гостей
Гость | Клиент отеля, бронирует номер самостоятельно | Просмотр каталога номеров и цен, создание и отмена своих бронирований
Персонал | Сотрудник, ответственный за уборку номеров | Просмотр списка номеров для уборки
## 5. Функциональные требования
1. Система должна позволять администратору выполнять поиск свободных номеров по заданным датам и количеству гостей.
2. Система должна позволять администратору создавать новое бронирование с привязкой к конкретному номеру или категории.
3. Система должна позволять администратору оформлять заселение с регистрацией гостя и закреплением за ним номера.
4. Система должна позволять администратору оформлять выселение с автоматическим расчетом итоговой стоимости проживания.
5. Система должна автоматически изменять статус номера при заселении и выселении.
6. Система должна позволять администратору просматривать календарь загрузки всех номеров на текущий месяц.
7. Система должна позволять гостю регистрироваться в системе и просматривать историю своих бронирований.
8. Система должна позволять гостю отменять свое бронирование с автоматическим освобождением номера.
9. Система должна позволять персоналу (горничной) отмечать номер как готовый для заселения после уборки.
10. Система должна проверять дубликаты гостей по паспортным данным при регистрации.
## 6. Концепция информационной системы
Информационная система предназначена для автоматизации основных бизнес-процессов гостиницы: управления номерным фондом, обработки бронирований, регистрации гостей, оформления заселения и выселения. Система повышает прозрачность загрузки номеров и снижает временные затраты персонала.
Основные возможности: ведение единой базы номеров и их категорий, ведение единой базы гостей с историей проживания, оформление и отмена бронирований, оформление заселения и выселения гостей, автоматический расчёт стоимости проживания, формирование отчетов по загрузке и доходам, самостоятельное бронирование номеров через веб-портал (или сайт)
